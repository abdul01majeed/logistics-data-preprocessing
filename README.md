# logistics-data-preprocessing
A Python-based data analytics project demonstrating data collection, cleaning, missing-value handling, outlier detection, and normalization using a logistics supply chain dataset.


Logistics Data Collection, Cleaning and Preprocessing
Project Overview

This project demonstrates a complete data preprocessing workflow for logistics and supply chain analysis using Python.

The project uses the publicly available DataCo Smart Supply Chain dataset as a reference to demonstrate data collection, data exploration, data cleaning, missing-value handling, outlier detection, and normalization.

Objectives
Collect and explore logistics data.
Identify and handle missing values.
Detect and remove duplicate records.
Identify and manage outliers using the IQR method.
Apply Min-Max normalization.
Prepare a clean dataset for further analysis.
